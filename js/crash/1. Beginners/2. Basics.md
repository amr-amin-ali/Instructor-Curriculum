4. Dynamic Typing

   There are 2 types of programmiong languages
   1. ***Statically-Typed*** languages.\
        Variable types is determineed at ***compile*** time

   2. ***Dynamically-Typed*** languages.\
        Variable types is determineed at ***run*** time

    **Example** for js as a dynamic language

    ```js
        let name = "AMR";
        console.log( typeof name ); // string
        name = 66;
        console.log( typeof name ); // number
    ```

5. Objects
   
   There are 3 reference  types
   1. Object
   2. Array
   3. Function

    - What are objects
    - Using objects  to gather related variables tomake the code cleaner
    - Object consists of keys and values
    - Keys are called properties
    - 

    **Example** for object literal declaration

    ```js
        // Without object
        let name = "MOSH";
        let age = 40;
        // Using object
        let person =  {
            name: 'MOSH',
            age: 40
        }
        console.log(person);
    ```

    There are 2 ways to work with these properties:
    - The ***dot*** notation\
        Change the value
        ```js
            person.name = "HELLO";
        ```
        Read the value
        ```js
            console.log(person.name);
        ```
    - The ***bracket*** notation\
        Change the value
        ```js
            person['name'] = "HELLO";
        ```
        Read the value
        ```js
            console.log(person['name']);
        ```
    > ***dot*** notation is cleaner while ***bracket*** notation is useful when we don't know the property name untill the  runtime

    Example
    ```js
        let selection = 'name';
        console.log(  person[selection]  );
    ```

7. Functions

    Functions are reference types.\
    Functions are a set of statements that performs a task or calculate a value.
   1. Function declaration
        ```js
            function greet(){
                // Here is called => function's body
                console.log('Hello world!');
            }// function declaration is not followed by ;
        ```
    2. Function call 
        ```js
            greet();
        ```
    3. Function parameters
        ```js
            function greet(name){
                console.log('Hello ' + name);
            }
            greet('John');
            greet('Mary');
        ```
    4. Function can has multiple parameters
        ```js
            function greet(firstName, lastName){
                console.log('Hello ' + firstName + ' ' + lastName);
            }
            greet('Amr', 'Amin');
            // try without a value
            greet(); // undefined
        ```
