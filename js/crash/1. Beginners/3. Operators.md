# Operators

1. Arithmetic Operators
   - Used for performing calculations
   -  `+` the addation operrator
      -  Is a binary operators `takes two operands`
      -  Example
            ```js
                let x = 10;
                let y = 3;
                console.log( x + y );
            ```
        - `x + y`  is called **`statement`** or **`expression`**
        - **`Expression`** I=is some thing that produces a value.
   - Other operators **`-` `*` `/` `%` `**`**
   - The increment `++` and decrement `--` operators
     - **Post** _vs_ **Pre** Increment/Decrement

2. Assignment Operators
    ```js
        let x = 5;
    ```
   - The compount assignment operator
        ```js
            let x = 5;
            x = x + 9;
            x += 9;
            x *= 9;
            x -= 9;
            x /= 9;
            x %= 9;
        ```

3. Comparison Operators\
   We use it to compare the value of a variable with some thing else
   Example
   ```js
    let x = 5;
    console.log( x > 0 );
   ```
   **NOTE:** The result of a comparison expression is a ***boolean***\
   Other comparison operators are `>` `>=` `<` `<=` `==` `===` `!=` `!==`

4. Equality Operators
   1. Loose equality operator `==`
   2. Strict equality operator `===`
   3. `==` vs `===`\
        `==` always try to convert the value of the right operand to match the type of the left operand\
        Examples
        ```js
            console.log(1 == 1);
            console.log('1' == 1);// converts 1 to string
            console.log(true == 1);// converts 1 to boolean (1 is truthy)
        ```
5. Ternary Operators\
   Explain a a simpler syntax of the **if**\
   Example
   ```js
        let points = 110;
        let category = points > 100 ? 'GOLD' : 'SILVER';
   ```
6. Logical Operators with booleans\
   We use logical operators to make decisions of multiple conditions\
   We have 3 logical operators: **logical AND**, **logical OR** and **NOT**
   1. Logical AND `&&`\
        Returns **_true_** if both conditions are true and **_false_** otherwise\
        Example
        ```js
            let isOld = true;
            let isWorking = true;
            let eligible = isOld && isWorking;
            console.log( eligible );
        ```
   2. Logical OR `||`\
        Returns **_false_** if both conditions are false and **_true_** otherwise\
        Example
        ```js
            let isOld = true;
            let isWorking = true;
            let eligible = isOld || isWorking;
            console.log( eligible );
        ```
   3. Logical NOT `!`\
      It reverts the boolean
        ```js
            console.log( !eligible );
        ```

7. Logical Operators with Non-booleans\
   The result of a boolean expression is not necessarily a boolean\
   Example
    ```js
        console.log( false || true ); // true
        console.log( false || 'AMIN' ); // 'AMIN'
        console.log( false || 1 ); // 1
    ```
    > When JS engine try to evaluate an expression, it looks at each operand
    > If that operand is not a boolean true or false, it will try to evaluate it to
    > what so called **_truthy_** or **_falsy_**

    ----------------------------------------------------------------
    **Falsy values are:**
    - undefined
    - null
    - 0
    - false
    - ''
    - NaN
    --------------------------------------
    **any thing else is truthy**

    ----------------------------------------------------------------
    **What is short circuiting**
    ```js
        console.log( false || 1 || 2 ); //  2 
    ```
    Usage example for truthy/falsy values
    ```js
        let userColor = 'red';
        let defaultColor = 'green';
        let currentColor = userColor || defaultColor;
    ```
