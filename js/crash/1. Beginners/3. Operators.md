## 3. Comparison Operators<br>

We use it to compare the value of a variable with some thing else <br>


Other comparison operators are `>` `>=` `<` `<=` `==` `===` `!=` `!==`

## 4. Equality Operators

1. Loose equality operator `==`
2. Strict equality operator `===`
- `==` vs `===`<br>
    `==` always try to convert the value of the right operand to match the type of the left operand<br>
    Examples:
    ```js
        console.log(1 == 1);
        console.log('1' == 1);// converts 1 to string
        console.log(true == 1);// converts 1 to boolean (1 is truthy)
    ```

## 6. Logical Operators with booleans<br>

We use logical operators to make decisions of multiple conditions<br>
We have 3 logical operators: **logical AND**, **logical OR** and **NOT**
1. Logical AND `&&`<br>
    Returns **_true_** if both conditions are true and **_false_** otherwise<br>
    Example
    ```js
        let isOld = true;
        let isWorking = true;
        let eligible = isOld && isWorking;
        console.log( eligible );
    ```
2. Logical OR `||`<br>
    Returns **_false_** if both conditions are false and **_true_** otherwise<br>
    Example
    ```js
        let isOld = true;
        let isWorking = true;
        let eligible = isOld || isWorking;
        console.log( eligible );
    ```
3. Logical NOT `!`<br>
    It reverts the boolean
    ```js
        console.log( !eligible );
    ```

## 7. Logical Operators with Non-booleans<br>

The result of a boolean expression is not necessarily a boolean<br>
Example:
```js
    console.log( false || true ); // true
    console.log( false || 'AMIN' ); // 'AMIN'
    console.log( false || 1 ); // 1
```
> When JS engine try to evaluate an expression, it looks at each operand<br/>
> If that operand is not a boolean true or false, it will try to evaluate it to<br/>
> what so called **_truthy_** or **_falsy_**

----------------------------------------------------------------
**Falsy values are:**
- undefined
- null
- 0
- false
- ''
- NaN
--------------------------------------
**any thing else is truthy**

----------------------------------------------------------------
**What is short circuiting**
```js
    console.log( false || 1 || 2 ); //  2 
```
Usage example for truthy/falsy values
```js
    let userColor = 'red';
    let defaultColor = 'green';
    let currentColor = userColor || defaultColor;
```

## 8. BitWise Operators

1. Binary System
    > **1** is represented as **00000001**                <br>
    > **2** is represented as **00000010**                <br>
2. The bitwise OR is represented by a single vertical pipe **_|_**
    ```js
    console.log( 1 | 2 ); // 3
    ```
3. The bitwise AND is represented by a single ampersand **_&_**
    ```js
    console.log( 1 & 2 ); // 0
    ```
4. **How the bitwise works**
    > It compare each two bits, if either of these bits is 1 <br>
    > Then the result is 1, otherwise it will be ZERO        <br>
    > **<u>Example for the bitwise OR:</u>**                 <br>
    > 1============ 00000001                                 <br>
    > 2============ 00000010                                 <br>
    > Result========= 00000011                               <br>
    > **<u>Example for the bitwise AND:</u>**                <br>
    > 1 = 00000001                                           <br>
    > 2 =  00000010                                          <br>
    > Result =  00000000                                     <br>
5. Real world example
    ```js
        let readAccess = 4;
        let writeAccess = 2;
        let isFullAccessAllowed = readAccess & writeAccess;

        if(isFullAccessAllowed){
            console.log('Access granted.')
        }else{
            console.log('Access denied.')
        }
    ```
